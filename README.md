# Path to AI Agent Engineer

面向已有开发经验的软件工程师，通过 **3 个递进项目**，学习构建可评估、受控、可恢复的 AI Agent。
不从零教授 Python，不训练基础模型，也不以框架数量衡量能力。

## 从这里开始

1. 按[环境准备](./docs/setup.md)安装要学习的项目，不需要 API Key。
2. 用[第 00 课](./projects/tool-agent/lessons/00-agent-overview.md)观察一次工具调用与终止，再从项目一开始实现。
3. 每课交付修改、运行结果和简短解释；每个项目完成一次独立迁移任务。

已熟悉结构化输出、评估和有限重试的读者，可以通过[项目一验收](./projects/baggage-extractor/README.md#项目验收)后直接进入第 05 课。

## 学习和验证边界

- **默认离线**：提取器使用 Stub / HTTP Mock，工具 Agent 使用脚本化响应；安装依赖可能需要联网。
- **离线不等于模型有效**：脚本响应只演示机制，程序测试只验证给定输入下的行为。真实模型评估需另外显式运行。
- **真实调用自愿启用**：只发送允许外发的数据，先确认请求量与费用。没有账户不阻塞离线学习，未做实验如实标记。
- **结果必须有证据**：不要把未运行写成通过；模型、Prompt、数据与权限变化后按影响范围回归。失败不得从统计分母中消失。
- **安全由程序实施**：模型输出和工具内容都不可信；授权、审批、预算和终止不能只靠提示词。
- **AI 编程协作**：每个项目可委派一个小任务，但须自行审查 diff、运行测试并解释实现，不要求提交聊天流水账。

项目结束使用[成果报告](./templates/project-report.md)。会运行参考实现不等于学会；还需完成练习与迁移任务。

## 按需扩展，而非必修

理解本地工具后再学 MCP；需要复用任务知识时再学 Skills。
框架重构、长期记忆、混合检索、多 Agent、微调和推理部署不在本版必修范围。
引入它们前，先用同一任务集证明收益，不为追逐名词增加复杂度。

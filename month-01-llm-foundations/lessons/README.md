## 如何学习

1. 先读任务并预测行为，再运行参考测试确认环境。
2. 在自己的分支完成变式任务，对照实现解释差异；现有测试全绿不等于自己学会。
3. 用[学习记录](../../templates/learning-log.md)保留命令、实际结果、失败原因与待解决问题，个人记录保存在自己的 Fork 中。

环境失败先查[排错表](../../docs/setup.md#常见问题)，测试通过但无法解释时先完成复盘，不靠跳过测试继续。
每个项目完成一次[AI 编程协作练习](../../docs/assessment.md#项目交付与-ai-编程协作)，不替代独立理解和验收。

没有 API Key 也能完成前七课的离线任务。
真实模型运行是第 2、5、6、7 课的可选实验，会产生外部请求及潜在费用。
第 6 课先用保存的预测校准评分器，再显式选择是否运行真实模型；普通 pytest 不执行付费评估。
完成前七课后，按[学习推进条件](../../docs/assessment.md#学习推进与项目交付)核对证据；
真实模型实验、Docker、英文、会员叠加与更大数据集不阻塞后续概念和离线工程学习。
模块 03 尚在规划中；项目部署与完整交付按[项目要求](../README.md#6-必做闭环完成定义)另行验收。

# 第一月样板课程

[返回项目计划](../README.md) · [环境配置](../../docs/setup.md) · [验收指南](../../docs/assessment.md)

前五课均有参考实现与离线验收。
当前未提供逐课 Git 标签或独立练习包，
请在自己的工作副本中完成小步变式练习，不需要删除当前实现来“回到第 1 天”。

| 课程 | 前置 | 建议投入 | 结果 |
| --- | --- | --- | --- |
| [01 工程初始化](./01-project-setup.md) | Git、基本 Python | 1～2 小时 | 安装、配置、离线测试 |
| [02 模型调用与契约](./02-model-calls.md) | 01、HTTP、JSON | 2～3 小时 | 请求与响应契约、HTTP Mock、计时 |
| [03 异步与错误处理](./03-error-handling.md) | 02、async/await | 2～3 小时 | 错误分类、有限重试、退避测试 |
| [04 领域 Schema](./04-domain-schema.md) | 03、Pydantic 基础 | 2～3 小时 | 领域模型、确定性校验、JSON Schema |
| [05 结构化提取闭环](./05-structured-extraction.md) | 04、Provider 协议 | 3～5 小时 | 结构化请求、提取器、异常和 CLI |

每课按照“先预测 → 跑参考测试 → 完成变式任务 → 对照实现 → 记录结论”学习。
现有测试通过仅说明参考实现可运行，自己的新增测试与解释才是学习证据。
项目学习还包括一次[AI 编程协作练习](../../docs/coding-agent-workflow.md)；它不替代独立理解和测试验收。

没有 API Key 也能完成前五课的离线任务。
真实模型运行是第 2 课和第 5 课的可选实验，会产生外部请求及潜在费用。
完成前四课后，可通过第 5 课的 Stub 和 HTTP Mock 在不访问真实模型的情况下完成结构化提取闭环。
先完成[第一月必做范围](../README.md#25-第一版范围)，英文、会员叠加与更大数据集属于进阶，不阻塞进入工具调用学习。
